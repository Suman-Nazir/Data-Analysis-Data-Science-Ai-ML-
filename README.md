# Diabetes Prediction & Machine Learning Analysis
## 📌 Project Overview
This project focuses on analyzing and predicting diabetes outcomes using Machine Learning and Deep Learning techniques in Python. The dataset was sourced from Kaggle and the complete project was implemented in Google Colab.

The project includes:
- Data preprocessing and cleaning
- Exploratory Data Analysis (EDA)
- Feature scaling
- Machine Learning model training and evaluation
- Deep Learning using Artificial Neural Networks (ANN)
- Clustering and PCA visualization
- Ethical analysis of AI in healthcare

---

## 🛠 Technologies & Libraries Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- TensorFlow / Keras

## 🤖 Machine Learning Models Used
- Logistic Regression
- Decision Tree

- K-Nearest Neighbors (KNN)
- Naive Bayes
- Artificial Neural Network (ANN)

---

- Data Cleaning
- Missing Value Handling
- Feature Scaling
- Model Evaluation
- K-Means Clustering
- PCA (Principal Component Analysis)
- Feature Importance Analysis

---

## 📈 Evaluation Metrics
The models were evaluated using:
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

---

## 🔍 Key Insights
- Glucose and BMI were among the most influential features for diabetes prediction.
- Ensemble learning and neural networks showed strong predictive performance.
- Feature scaling significantly improved KNN and ANN model performance.
